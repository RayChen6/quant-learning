# 策略开发 — 核心知识点速览

## 1. 策略分类

| 类型 | 逻辑 | 适用市场 | 持仓周期 |
|------|------|---------|---------|
| 趋势跟踪 | 追涨杀跌，顺势而为 | 单边市 | 中长期 |
| 均值回归 | 价格偏离均值后回归 | 震荡市 | 短中期 |
| 统计套利 | 相关资产价差回归 | 任意 | 短期 |
| 事件驱动 | 财报/并购/分红等事件 | 任意 | 不定 |
| 高频做市 | 提供流动性赚价差 | 任意 | 秒级 |

---

## 2. 动量策略

**时序动量**：过去 N 月正收益则做多
$$\text{Signal}_t = \text{sign}(r_{t-N:t})$$

**截面动量（横截面）**：
- 每期做多收益最高的前20%，做空最低的20%
- 通常用过去12个月收益，跳过最近1个月（反转效应）

**双均线策略**：
```
快线（MA5）上穿慢线（MA20）→ 买入信号
快线下穿慢线 → 卖出信号
```

---

## 3. 均值回归策略

**布林带（Bollinger Bands）**：
- 中轨 = MA(N)
- 上轨 = MA(N) + k × σ
- 下轨 = MA(N) - k × σ
- 价格触及下轨买入，触及上轨卖出

**Z-Score**：
$$Z = \frac{P - \mu}{\sigma}$$
|Z| > 2 时认为价格偏离，反向交易

---

## 4. 配对交易（统计套利）

```
1. 找到协整的股票对 (A, B)
2. 计算价差 Spread = A - β×B
3. Spread 偏高时做空 A、做多 B
4. Spread 回归均值时平仓
```

## 5. 策略开发检查清单

- [ ] 信号逻辑是否有经济学解释
- [ ] 是否有前视偏差
- [ ] 样本外（Out-of-sample）表现是否稳定
- [ ] 参数敏感性如何（小幅调参是否崩溃）
- [ ] 考虑手续费和滑点后是否仍盈利
- [ ] 容量估计（策略能承载多少资金）
